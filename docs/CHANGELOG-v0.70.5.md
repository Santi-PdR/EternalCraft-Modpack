# Eternal Craft Launcher 0.70.5

- Personal mods now create compatibility warnings only for an actual unsupported client environment or a duplicate project ID; filename similarity alone no longer produces a warning.
- Disabled personal mods are excluded from compatibility checks until enabled.
- The update center now distinguishes a verified launcher version from a pending, unconfigured, or failed update check instead of showing a false “everything is up to date” state.
- Bumped the launcher and manifest minimum version to 0.70.5.
