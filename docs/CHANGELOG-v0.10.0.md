# Eternal Craft Launcher 0.11.0

- Actualizaciones de mods personales instalados desde Modrinth.
- Filtro de mods actualizables y acción “Actualizar todo”.
- Preview seguro antes de publicar el modpack.
- Flujo developer `test-1 → SIEGE` con comparación por SHA-256 y promoción selectiva.
- Backups automáticos al reemplazar un mod de SIEGE desde test-1.
- La ventana recuerda posición, tamaño y estado maximizado.
- Densidad cómoda/compacta y profundidad visual configurable.
- Fondos con rotación automática cada 5 o 15 minutos.
- Onboarding muestra RAM, resolución, GPU y Java autoconfigurados.
- Temas con composición y fondos propios más diferenciados.
