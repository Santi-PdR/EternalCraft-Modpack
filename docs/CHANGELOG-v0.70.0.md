# Eternal Craft Launcher 0.70.0

Salto mayor de estabilidad y publicación para distinguir claramente esta tanda de mejoras.

- Clasificación oficial de mods sincronizada después de publicar desde cualquier instancia SIEGE configurada.
- Publicación del manifiesto más segura y verificable, con recuperación de assets y validación de huellas.
- Inicio del launcher más resistente a comprobaciones lentas, errores IPC y páginas vacías.
- Actualizaciones y reparaciones reutilizan comprobaciones previas para reducir hashes y tiempos de espera.
- Estado del servidor validado antes de mostrarlo como confirmado y con límite de respuesta.
- Navegación responsive ajustada para evitar solapamientos en ventanas estrechas.
- La build muestra ahora `0.70.0` en la interfaz, diagnóstico, manifest y agentes HTTP.
