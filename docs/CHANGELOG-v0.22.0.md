# Eternal Craft Launcher 0.22.0

Salto de cinco versiones menores centrado en seguridad, mantenimiento y acabado.

- Manifest endurecido contra rutas inseguras, duplicados, hashes inválidos y URLs no seguras.
- Descargas remotas requieren HTTPS salvo servidor de desarrollo local.
- Centro de conectividad para canal del pack, catálogo externo y GitHub.
- Panel de mantenimiento con tamaños de mods/config/cache/backups/logs.
- Limpieza de logs antiguos desde Ajustes.
- Página inicial configurable.
- Advertencias de compatibilidad controlables.
- Preview de publicación muestra archivos y queda ligado a fingerprint de la fuente.
- Publicación se bloquea si SIEGE cambió después del preview.
- Windows Jump List con Jugar y Actualizaciones.
- Nuevos filtros de mods locales y orden por actualización.
- Pulido visual y responsive adicional.
