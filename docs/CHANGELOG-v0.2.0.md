# Eternal Craft Launcher v0.2.0

- Primer inicio bloqueado hasta elegir nick de Minecraft.
- Detecta `~/.sklauncher/instances/siege/` automáticamente.
- Puede clonar esa instancia como base del modpack sin modificar la original.
- No copia mundos, capturas, logs, cachés ni opciones personales.
- Aplica un preset limpio de controles y opciones generales.
- Botón para volver a aplicar el preset.
- Botón para resincronizar el modpack desde la instancia SIEGE.
- Modo local funcional sin manifest remoto.
- Favicon del servidor mostrado en el panel cuando el servidor lo entrega.
- Abrir carpeta ya crea el directorio si todavía no existe.
- Detección automática de Java 17; evita lanzar 1.20.1 con Java 25 por accidente.
- Versión del launcher subida a 0.2.0.
